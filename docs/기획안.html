서비스 이름 하나 넣으면, Instagram과 Threads가 돌아간다.

「홍보실」(임시 이름) — 펜시브 서비스의 Instagram·Threads 계정을 개설부터 게시·광고·감시까지 맡아 돌리는 운영 도구. 사람 손은 세 번(가입·연결·프로필)만 간다.

결론

가입만 사람이 하고, 그 뒤는 전부 시스템이 한다. 공식 Meta API만 쓴다(비공식 자동화로 계정이 정지되는 길은 아예 막는다).

  • 서비스 이름 → 계정명 후보 6개 · 바라는 점을 적어 다시 추천 · 있는 이름은 빠지고 새 후보로 채움
  • 사람이 적은 설명으로만 소개문 3안 · 프로필 이미지
  • 소재(제품 이미지·설명서·홈페이지)에서 게시물 생성 — 초안 → 한 번 더 다듬기(두 번 쓰기)
  • 예약 → 게시 — 적게, 잘: Instagram 주 2 · Threads 평일 하루 1 (슬롯은 설정에서)
  • 성과 좋은 글 자동 광고 (Instagram 피드 + Threads 지면)
  • 지표·댓글·토큰·실패 감시, 매일 아침 요약
  • 이름 확인 — 후보마다 ↗ 로 Instagram 에서 열어 보고 ✓ 비었음 / ✕ 있음. 서버는 Instagram 을 긁지 않는다(약관·차단).
  • ① 가입 — 이름·사용자 이름을 복사해 붙여넣기. 가입 화면이 최종 판정 — 있다고 나오면 「이미 있대요」로 다시 고르기. 3분.
  • ② 연결 — 프로 계정 전환 · Facebook 페이지 연결 · 앱 권한 허용. 클릭만.
  • ③ 프로필 — 서비스 설명 적기 → 소개문 3안 중 고르고 고치기 → 사진·소개 붙여넣기. API가 프로필 수정을 막아 둬서 사람이 넣는다.
  • 광고는 첫 한 번 결제수단·사업자 인증(Meta 비즈니스)이 더 필요하다.
  • 공식 API 한도 안에서 — Instagram 하루 100건, Threads 하루 250건
  • 미디어는 공개 URL(Workers KV)로 — Meta가 가져가는 구조
  • 처음 2주는 승인 후 게시, 그 뒤 자동 전환 제안
  • 비밀값(Meta 앱 키·AI 키·입장 암호)은 Cloudflare 변수에 직접 등록

왜 가입을 자동화하지 않나. Meta 약관이 자동 계정 생성을 금지하고, 가입 화면은 캡차·전화 인증으로 봇을 막는다. 우회해서 만든 계정은 생기자마자 정지된다. 가입 3분을 사람이 하고 나머지 100%를 시스템이 맡는 쪽이 결과가 좋다.

구조

Cloudflare Worker 하나가 화면·API·크론을 다 맡는다. Pages가 아니라 Workers인 이유는 크론(예약 게시)이 Workers에만 있어서다. 큐는 쓰지 않는다 — 예약 표(D1)를 5분 크론이 읽는 것으로 충분하다.

배포

GitHub main 푸시 → Cloudflare Workers Builds 자동 배포 → instagram.pensieve.kr. 연결은 브레인 스토밍·BM 때처럼 Claude가 Cloudflare 대시보드에서 잡는다(Chrome). 비밀값(PASSWORDS·ANTHROPIC_API_KEY)은 BM·브레인 스토밍과 같은 이름으로 사용자가 Cloudflare 변수에 직접 등록.

Meta 쪽 한 번 설정 (사람)

개발자 앱 만들기 → Instagram·Threads 제품 추가 → 앱 역할에 본인 계정. 자체 계정만 운영하면 앱 심사 없이 개발 모드로 충분하다. 광고(Marketing API)는 비즈니스 인증·접근 심사가 더 있어 2차로 뺐다.

릴스 영상 (2차)

Workers에서는 영상 합성(ffmpeg)이 안 돈다. 1차는 이미지 카드·Threads 글. 릴스는 2차에서 Cloudflare Containers 기준으로 가고 외부 렌더 API를 보조로 둔다 — 자체 리눅스 서버는 보안 사고 이력과 미세팅 때문에 제외.

구현 현황 · 남은 설정

instagram.pensieve.kr 배포 완료. 코드는 Pensieve-VR/instagram main, push 하면 자동 배포. 남은 것은 Cloudflare 비밀값(암호·AI 키·SESSION_SECRET)과 Meta 앱 키 — 사람이 한 번 할 일.

있음 — 1차 전부

  • 암호 입장(PASSWORDS) · 공간별 서비스 묶음
  • 시작 → 계정명 후보 5개(빈 이름 확인) → 게이트 ①②③

  • 소재 창고(JPG·글·링크 → 사실만 추림) · 슬롯 설정 · 각도 8개 순환
